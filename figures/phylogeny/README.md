# Phylogeny

This directory contains phylogenetic analyses of NS5 protein sequences from representative flaviviruses.

The phylogenetic reconstruction provided evolutionary context for downstream conservation analyses and helped identify residues and structural regions that are highly conserved across related viruses.

## Files
- `IQTreeFinalV.2.pdf` — High-resolution version of the tree for detailed inspection.

## Notes
This work was completed as part of an undergraduate research course and is not a peer-reviewed publication.
