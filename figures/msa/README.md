# Multiple Sequence Alignment (MSA)

This directory contains the multiple sequence alignment used for downstream evolutionary analyses of the West Nile Virus NS5 protein.

The alignment includes representative flavivirus NS5 sequences and served as the basis for:

- phylogenetic reconstruction,
- evolutionary rate estimation,
- conservation analyses used to prioritize candidate antiviral targets.

Files:
- `NS5_AlignedMSA.png`: visualization of the final alignment.
- `NS5_msa_renamed.fasta`: aligned sequences used in subsequent analyses.

## Notes
This work was completed as part of an undergraduate research course and is not a peer-reviewed publication.
