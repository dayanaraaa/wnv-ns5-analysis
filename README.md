# wnv-ns5-analysis
Drug target analysis of West Nile Virus NS5 protein using bioinformatics and structural methods.

# West Nile Virus NS5 Drug Target Analysis

This project investigates the West Nile Virus NS5 protein to identify and prioritise potential antiviral binding sites using a multi-step bioinformatics pipeline.

The analysis integrates sequence-based, structural, and evolutionary methods to evaluate druggability and functional importance of predicted pockets.


## Biological Background
West Nile Virus (WNV) is a flavivirus responsible for significant neuroinvasive disease in humans. NS5 is a key viral protein involved in RNA replication and is a major antiviral drug target candidate.

## Methods

The following pipeline was used:

- Sequence retrieval and homology search (BLAST)
- Multiple sequence alignment and phylogenetic analysis
- Structural analysis and visualization (PyMOL)
- Disorder prediction (IUPRED)
- Druggability scoring (PockDrug)

## Key Results

- Reduced candidate binding pockets from multiple initial sites to 2 high-priority druggable regions
- Prioritisation based on evolutionary conservation, structural accessibility, and disorder profiles

## Tools Used

BLAST, Jalview, PyMOL, IUPRED, PockDrug, Python
