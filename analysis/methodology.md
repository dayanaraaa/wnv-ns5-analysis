# Methodology

The computational analyses presented in this repository were performed as part of an undergraduate research course at Florida International University.

Methods utilized included:

- BLAST
- MUSCLE (Jalview)
- IQ-TREE
- Rate4Site
- AlphaFold/ColabFold
- IUPred
- PockDrug
- PyMOL
- SQL database integration

The scripts and computational workflows used in the course are not included in this repository, as they were developed and maintained by the instructional program.

This repository serves as an archive of the figures, reports, and educational outputs generated during the project.
